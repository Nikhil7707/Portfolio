## 🌟 Introduction

Welcome to **Dynamic Orbit**, the personal portfolio of **Amrit Tyagi**. This project showcases my journey as a Software Developer and IoT enthusiast, featuring a modern, responsive design with interactive 3D elements.

> "Building scalable applications and innovative IoT solutions."

## 🛠️ Tech Stack

Built with cutting-edge web technologies for performance and aesthetics:

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/) + [Shadcn UI](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/) & [Drei](https://github.com/pmndrs/drei)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand) (implied) / React Query
- **Routing**: [React Router](https://reactrouter.com/)

## ✨ Features

- ** immersive 3D Experience**: Integrated 3D models and environments using Three.js.
- **📱 Fully Responsive**: Seamless experience across mobile, tablet, and desktop devices.
- **🎨 Modern UI/UX**: Clean aesthetic with polished components from Radix UI and Shadcn.
- **⚡ High Performance**: Fast load times optimized by Vite and code splitting.
- **📊 Data Driven**: Dynamic content rendering from structure JSON data.

## 🚀 Getting Started

Follow these steps to run the project locally:

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Nikhil7707/Portfolio.git
    cd Portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```
    Open http://localhost:8080 to view it in the browser.
